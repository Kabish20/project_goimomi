## 3. Database setup and data import

Database: `goimomi_db`. Owner: `goimomi_user`.

All Django migrations were applied before importing `goimomi_db_dumpdata.json`. The fixture contains 20,553 records across 27 models. Its SHA-256 is:

```text
6bbddc0ae1650d4104bc15c476e8818fdaec47ec716825e9214ff7d5e32ccccd
```

The import script runs `loaddata` and verification in a database transaction. It compares every supplied field, checks relationships and ID sequences, and writes `/root/goimomi-import/import-report.json`. Fields absent from this older fixture retain the current model defaults.

To inspect the report or recheck the imported values without importing again:

```bash
cat /root/goimomi-import/import-report.json
/var/www/goimomi-venv/bin/python /root/goimomi-import/import_and_verify.py --verify-only
```

The verification compares the database to the original fixture; changes made later through the application can legitimately differ.

Backups:

- `/var/backups/goimomi/before-import-20260921.dump`: migrated database before loading the fixture.
- `/var/backups/goimomi/after-import-20260921.dump`: database after successful import.

The fixture contains no authentication users. Existing admin passwords cannot be recovered from this file. To create a new administrator interactively:

## 6. Install SSL after DNS resolves here

**Completed on 21 September 2026:** Let's Encrypt certificate installed for both names, valid until 20 December 2026. The enabled `certbot.timer` schedules renewals, and `certbot renew --dry-run --no-random-sleep-on-renew` succeeded. Nginx TLS configuration and Django settings before the change are backed up in `/root/goimomi-import/tls-backup`. The commands below document the setup; no reinstallation is needed.

Ensure the hosting provider permits inbound TCP ports 80 and 443. Then run:

```bash
certbot --nginx -d goimomi.com -d www.goimomi.com --redirect
```

Follow the interactive email and terms prompts. After the certificate is successfully installed, edit `/var/www/goimomi/goimomibackend/backend/server_settings.py` and change `SECURE_SSL_REDIRECT = False` to `SECURE_SSL_REDIRECT = True`.

```bash
systemctl restart goimomi
nginx -t
systemctl reload nginx
certbot renew --dry-run
systemctl status certbot.timer --no-pager
curl -I https://goimomi.com/
curl -I https://www.goimomi.com/
```

See the [Certbot Nginx instructions](https://eff-certbot.readthedocs.io/en/stable/using.html#nginx) and [Django fixture loading documentation](https://docs.djangoproject.com/en/4.2/ref/django-admin/#loaddata).
